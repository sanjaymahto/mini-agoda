# ADR 0002 - Vite as the build tool

- **Status:** Accepted (replaces an initial Webpack 5 setup)
- **Date:** 2026-11-14

## Context

Module Federation was born in Webpack 5. Historically Vite federation plugins
(e.g. `@originjs/vite-plugin-federation`) required remotes to be **built**
even in development, which hurt DX.

## Decision

Use **Vite 8** with the official **`@module-federation/vite`** plugin. It is
maintained by the Module Federation organisation, supports **dev-mode remotes
with HMR**, and interoperates with Webpack/Rspack hosts if we ever need it.

## Consequences

- ✅ Sub-second dev server start per app, instant HMR.
- ✅ Native CSS Modules, TS and JSX - no Babel/loader config.
- ✅ One small factory (`packages/vite-config`) configures every app.
- ⚠️ Remotes need `server.origin` and an absolute `base` in production so
  their assets resolve to their own host. The factory handles both.
- ⚠️ Federation uses top-level `await` → `build.target: 'esnext'` (modern browsers only).
